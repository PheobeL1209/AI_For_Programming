# GC Content Script

`gc_content.py` is a standard-library command-line utility for examining GC composition in FASTA data. Supply one FASTA file path as the positional input. The parser supports multiple records, joins sequence lines within each record, and uses each record’s header to label its result. For every nonempty sequence, the program calculates the percentage of bases that are G or C relative to the full sequence length, then prints the header and percentage rounded precisely to two decimal places. Sequences are case-insensitive; whitespace between sequence characters is removed during FASTA reading. Empty records are skipped with a warning, so they do not cause division by zero or stop other records from being processed. The optional `--min-gc <float>` argument filters results by percentage: only records strictly above the threshold are printed. For instance, `--min-gc 50` excludes records at 50% as well as those below it. The threshold must be between 0 and 100 inclusive.
